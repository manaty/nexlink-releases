Nexlink Desktop

An icon in your menu bar that tells you when a Nexlink message arrives. Clicking the notification opens the conversation on the web version — the app never renders a message.

Download

  • Windows — this machine Nexlink.Setup.0.1.0.exe Double-click. Per-user install, no administrator needed.
  • macOS (Apple silicon) — this machine Nexlink-0.1.0-arm64.dmg Drag to Applications. Unsigned: right-click → Open the first time.
  • Debian / Ubuntu — this machine nexlink-desktop_0.1.0_amd64.deb sudo apt install ./nexlink-desktop_0.1.0_amd64.deb
  • Omarchy / Arch — this machine Nexlink-0.1.0.AppImage chmod +x then run it. Needs fuse2: omarchy pkg add fuse2
First run opens the Nexlink sign-in window, keeps the session in your system keyring, and then lives in the menu bar. Turn on Launch at login there: Electron cannot receive Web Push, so notifications arrive while the app is running.
Machine-readable manifest, sizes and checksums

The app and any installer script can read /desktop/latest.json (version, per-OS URL, size, sha256). Verify a download with: 

sha256sum -c <<<"<hash>  <file>"
